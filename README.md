# Aarogya Surgical

Website for **Aarogya Surgical Industries Ltd. (ASIL)** — a clinical equipment house for Indian theatres, ICU and speciality clinics. Layout follows a hospital-supplier pattern (top bar, catalogue, turnkey setups, CSR, quotes) with an original catalogue and brand.

## Run locally

```bash
node server.cjs
```

Then open http://localhost:5173
